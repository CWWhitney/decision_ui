# Save Model Dialog

To save your model, you can open the "Save Model" dialog from the "File menu" by clicking on "Save As...", see [Main Menu](../). Then, the following dialog opens:

![To Account Tab](./account-tab.webp)

There are two ways to save your model: to your account in case you are logged in, and to a file.

## To Account

When saving your model to your account, you can change the name of your model again directly in the dialog. The name is the same name as defined in the "[Metadata](../../metadata)" page. This name is also the name that is shown for your model in the [Open Model Dialog](../open-model-dialog).

You can use the same name for two or more different models. Models with the same name are not overwritten, but are stored as separate models.

You cannot overwrite a previously saved model from the "Save Model" dialog. In order to overwrite an existing model, you need to open it first, modify it, and then save it by clicking on the "Save" menu entry from the "File" menu.

You may save up to 100 different models in your account.

By activating the "Autosave" feature, your model is automatically saved to your account every 5 minutes. You can enable or disable autosaving from the "File menu", see [Main Menu](../). Please consider that it is not possible to recover older versions of your model. If you would like to preserve a specific version of your model, save this model as a separate model and continue your work on your current model.

## To File

Saving your model to a file will ask your browser to download the model as a file. You can store this file wherever you prefer. You can later load this file again from the [Open Model Dialog](../open-model-dialog).
