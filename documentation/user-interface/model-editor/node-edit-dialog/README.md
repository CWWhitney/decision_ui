# Node Edit Dialog

The node edit dialog can be used to customize each node and define important options such that the overall model is calculatable.

You can access the node edit dialog either by double-clicking on variable nodes, or by clicking on one of the corresponding icons of the node toolbar, see [Model Editor](../):

The node editor dialog consist of various subpages or tabs. Some of them are only accessible for certain types of nodes:

- [General Tab](./general-tab) - enter a name and description for a node
- [Function Tab](./function-tab) - define how the node variable is calculated
- [Data Tab](./data-tab) - a visualization of the node's calculated value
- [Analyze Tab](./analyze-tab) - options to influence how an estimate node can be interacted with on the [Analyze Model](../../analyze-model) page
- [Style Tab](./style-tab) - various options to influence how the node is drawn on the work space

Besides, in top right corner of the node edit dialog, you can access additional functions. From left to right, the following functions are available:

- "Undo" - reverts your most recent change to the current model
- "Redo" - reapplies changes that were previously undone by using the "undo" function
- "Maximize" - increases the size of the node edit dialog to fit the whole browser window
- "Help" - opens this help page
- "Close" - closes the dialog
